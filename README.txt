Weapon Cursor Swing Timer  (WoW Forever)
========================================

EN: Shows your swing timer as rings around the mouse cursor.
    Install: copy the "WeaponCursorSwingTimer" folder into your WoW Forever
    Interface\AddOns folder and restart the game.
    Options: /wcst (or /swc), or Game Menu > Options > AddOns.
    Languages: English, Deutsch, Français, Español, Italiano, Português, Русский
    (chosen automatically from your game client language).

DE: Zeigt den Swing-Timer als Ringe am Mauszeiger.
    Installation: Ordner "WeaponCursorSwingTimer" in den Interface\AddOns-Ordner
    deiner WoW-Forever-Installation kopieren und das Spiel neu starten.
    Einen alten Ordner "SwingCircle" bitte löschen.
    Optionen: /wcst (oder /swc) bzw. Spielmenü > Optionen > AddOns.

Commands / Befehle:
  /wcst                  options / Optionen
  /wcst size 70          size / Größe
  /wcst offset 30 -30    offset from cursor / Versatz
  /wcst combat           combat only / nur im Kampf
  /wcst reset            defaults / Standardwerte
